Data Analysis Repository
This repository contains various data analysis projects and visualizations, utilizing different datasets to explore relationships, trends, and insights. Key analyses include:

Key Analyses
MPG Analysis: Explored MPG distribution by cylinder count, horsepower-MPG relationship with regression, and MPG vs. weight across gear types using facet grids.
Airquality Dataset: Plotted daily temperature trends, monthly ozone averages, and wind speed distributions to analyze seasonal variations.
Iris Dataset: Visualized species differentiation using scatter plots, pairwise relationships, and histograms.
SQLite Databases: Created databases for course enrollment and sales data, querying, updating fees, and analyzing product sales.
Weather Data: Retrieved and visualized weather data for London, including 5-day forecasts and historical trends using the OpenWeatherMap API.
World Bank Data: Visualized education expenditure trends and analyzed Spain's spending, along with the relationship between female literacy and unemployment.
GDP Analysis: Analyzed GDP growth trends, filtered Asian data, and identified the top GDP continent in 2007 using the Gapminder dataset.
US Election Data: Analyzed key states, vote differences, and identified landslide results from US presidential election data.
Diamonds Dataset: Analyzed diamond prices and trends, identifying the most expensive cut and performing monthly price trend analysis.
NYC Flight Delays: Analyzed flight delays, identifying the most delayed airline, earliest arrival airport, and the month with the longest delays.
Diabetes Dataset: Performed exploratory data analysis (EDA) on diabetes data, including missing value handling and visualizations.
Student Data: Implemented data analysis for student data, including classification and missing value handling in R.
Data Manipulation: Performed filtering, sorting, and missing data handling in various datasets.
